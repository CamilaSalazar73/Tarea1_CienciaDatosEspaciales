# Tarea 1 - Ciencia de Datos Espaciales

## Análisis espacial de usuarios de teléfonos móviles (MOBILES)

En este trabajo se analiza la distribución espacial de la variable **MOBILES** en los países de Norteamérica, Centroamérica, Sudamérica y Caribe mediante mapas temáticos.

## Mapas realizados

- Dot Density Map (DDM)
- Proportional Symbol Map (PSM)
- Choropleth Map
